# <项目名> 项目记忆库

> **单一事实来源（source of truth）**。所有 AI agent（无论哪家工具）共读共写本目录；各家私有记忆只留指针。
> 格式与读写协议见 shared-agent-memory 规范（SKILL.md）。

## 用法

- 根目录 `AGENTS.md` 是**常驻摘要**（每次会话自动加载），只放跨模块红线与偏好。
- 本目录是**详细记忆**：碰到对应模块/主题的需求，先读对应文件再动手，不要凭印象写 SQL / 改流程。
- 标记「**必读**」的主题，改动前务必通读全文。
